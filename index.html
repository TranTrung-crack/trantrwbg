🌐 Chào mừng đến với trang web đầu tiên

Đây là một trang HTML cực kỳ đơn giản nhưng đầy đủ các thành phần cơ bản. Bạn có thể dùng làm mẫu để bắt đầu.

📌 Danh sách thứ tự (Ordered List)

  1. Bước 1: Mở file bằng trình duyệt
  2. Bước 2: Xem kết quả
  3. Bước 3: Chỉnh sửa nội dung trong file

📌 Danh sách không thứ tự (Unordered List)

  • HTML - Khung xương
  • CSS - Trang phục
  • JavaScript - Hành động (thêm sau)

💡 Mẹo nhỏ

Để chèn ảnh, bạn cần có file ảnh cùng thư mục hoặc dùng đường dẫn URL. Ví dụ bên dưới là ảnh mẫu từ internet (nếu không tải được, sẽ hiện chữ thay thế).
